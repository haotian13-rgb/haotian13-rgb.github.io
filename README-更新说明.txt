个人介绍网站（已按需求更新）

文件说明：
- index.html：页面内容、兴趣爱好链接、作品入口、36 首歌曲链接
- style.css：网站样式、响应式布局
- script.js：菜单、主题切换、滚动动画
- avatar.jpg：个人头像（请和其他文件一起上传到仓库根目录）

部署到 GitHub Pages：
1. 打开仓库 https://github.com/haotian13-rgb/haotian13-rgb.github.io
2. 将 index.html、style.css、script.js、avatar.jpg 上传并覆盖同名文件（README 可选）。
3. 确认 Settings → Pages 使用 main 分支的 /(root) 目录。
4. 等待部署后访问 https://haotian13-rgb.github.io/ 。

说明：手机浏览器一般禁止未交互的有声自动播放；酷狗分享页也不一定允许嵌入音频。因此音乐区保留每首歌的原始酷狗分享链接，点击“酷狗播放”即可跳转收听。
